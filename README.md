# ZEN Scout 幀探｜每一球，都找得到那一幀

> 幀是影像的最小單位；幀探，就是幫剪接師找到那一幀的球探。

這是 **ZEN Scout 幀探** 的唯讀展示版。ZEN Scout 幀探是一套替職業籃球隊管理比賽影像素材的系統：

- 從轉播畫面逐秒辨識比分板，再對上聯盟公布的逐球紀錄（PBP），把「誰在什麼時候做了什麼」對到各機位攝影機檔案的第幾秒。
- 剪接師輸入「球員＋動作」，就能找到那一球。

正式系統在球隊內部使用，跑在本機與公司內部的儲存設備上。這個展示版只取出 **1 場比賽**（2026-27 例行賽第 2 場 vs 國王）：

- 49 個球賽事件
- 115 段多機位片段（FX3／A7R V／ZR）
- 全部做成靜態網頁，不需要後端

## 資料夾結構

```
site/       作品首頁（評審第一個看到的頁面）
web/        線上體驗：事件搜尋＋多機位播放（index.html、search.js）
data/       events_1025.json：49 個事件與 115 段片段的公開資料
clips/      720p 片段（115 支，約 520 MiB；不進版控，由切片工具產生）
covers/     片段封面（115 張；不進版控）
tools/      匯出、切片、驗收、機敏掃描、打包、本機預覽的工具
local/      不公開的本地檔（切片計畫、認碟設定、測試紀錄；不進版控）
dist/       上線用的打包結果（由 build_dist.py 產生；不進版控）
```

## 在本機預覽

需要 Python 3（本專案在 3.11 上測試；Windows 用 `py`，其他系統用 `python3`），只用標準函式庫，不必安裝套件。

1. 在專案資料夾執行：`py tools\serve_local.py`
   - 想預覽打包結果，改用：`py tools\serve_local.py --root dist --port 4781`
2. 用瀏覽器開 `http://127.0.0.1:4780/`，會自動轉到作品首頁。

預覽伺服器只綁本機（127.0.0.1），區網的其他電腦連不到。它也只提供會公開的資料夾，不公開的 `local/`、`tools/`、`.git/` 一律回 404。

## 工具用途

| 工具 | 做什麼 | 備註 |
|---|---|---|
| `tools/export_1025.py` | 從正式系統的中央索引快照**複本**匯出 1025 這場的事件，產生公開的 `data/events_1025.json` 和不公開的切片計畫 | 需要內部資料，評審無法重跑；輸出已附在 `data/` |
| `tools/slice_1025.py` | 照切片計畫從原始素材碟切出 720p 片段與封面 | 預設**乾跑**（只印出指令）；`--apply` 才執行。用卷標＋碟上身分檔認碟，不寫死碟符；只讀來源、只寫專案資料夾 |
| `tools/verify_sources_1025.py` | 切片前比對來源檔（存在、大小、長度），記錄切片前後的大小與修改時間，證明來源沒被動過 | 只讀 |
| `tools/verify_clips_1025.py` | 驗收產出的片段 | 檢查解析度、編碼、影格率、長度、faststart，並確認沒有殘留相機中繼資料 |
| `tools/scan_secrets.py` | 機敏資訊掃描 | 掃 IP、網路路徑、碟符、uuid、token、帳號、內網主機名、來源檔名；只列檔名、行號和類型，不印出內容 |
| `tools/build_dist.py` | 用**白名單**組出上線用的 `dist/` | 只收網頁、資料、片段、封面；組完自動驗證檔數、單檔大小、機敏掃描、站內連結 |
| `tools/serve_local.py` | 本機預覽用的靜態伺服器 | 只綁 127.0.0.1、支援影片拖曳（Range） |

## 影片片段規格

- 每個事件取**事件前 5 秒、後 3 秒**。碰到原始檔的檔頭或檔尾就截短，不跨檔拼接。
- 1280×720、H.264（8-bit 4:2:0）、29.97 fps、AAC、faststart。
- 去除相機中繼資料：機身序號、拍攝時間、時間碼都會拿掉。
