# OPEN LAB 展示版

範例場次：2026-27 例行賽02 vs 國王（2026-10-25），只用球團自拍機位 FX3／A7R V／ZR，不用轉播畫面。

這是一個**獨立的專案**：程式是從 MAM 改寫過來的，正式 MAM 與它的 git 倉庫都不會被動到。

## 資料夾

| 資料夾 | 內容 | 公開 | 進版控 |
|---|---|---|---|
| `web/` | 網頁（目前只有 `search.js`：事件搜尋邏輯） | 是 | 是 |
| `data/` | `events_1025.json`：49 個事件、115 個機位片段的編號 | 是 | 是 |
| `tools/` | 匯出、切片、機敏掃描腳本 | 否 | 是 |
| `local/` | 切片計畫（含來源路徑）、認碟資料、掃描字詞、測試 | 否 | **否** |
| `clips/`、`covers/` | 切好的 720p 片段與封面（由 `slice_1025.py --apply` 產生） | 是 | 否 |

## 流程

1. `py tools\export_1025.py --db-dir <快照複本資料夾>`：從中央索引快照的**複本**產出 `data/events_1025.json` 和 `local/slice_plan_1025.csv`
   - 核對事件數 49、片段數 115，不符就停
2. `py tools\slice_1025.py`：乾跑，只印出指令和預估容量
   - 接上 DEA_S2627 後加 `--apply` 才會真的切
   - 認碟靠卷標加 uuid，不寫死碟符
3. `py tools\scan_secrets.py`：上線前掃描機敏資訊
   - `web/`、`data/` 必須是 0 筆
